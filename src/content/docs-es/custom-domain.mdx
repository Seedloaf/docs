---
title: Conectar un dominio personalizado
description: ¡Aprende cómo conectar tu dominio personalizado a tu servidor de Seedloaf!
---
### Paso 1: Abre la configuración DNS de tu dominio
Inicia sesión en tu proveedor de DNS o registrador de dominios (como Cloudflare, Namecheap o GoDaddy) y ve a la sección de Gestión de DNS para tu dominio.

### Paso 2: Crea un registro CNAME
Añade un nuevo registro CNAME con la siguiente configuración:
* **Tipo:** <code>CNAME</code>
* **Nombre:** <code>play</code> (crea <code>play.tudominio.com</code>)
* **Destino (Target):** ej. <code>tusubdominio.seedloaf.gg</code> (**no** incluyas el número de puerto ni el símbolo `:`)
* **Proxy:** Debe estar desactivado / deshabilitado

### Paso 3: Crea el registro SRV
Redirige el tráfico de Minecraft y el puerto personalizado a tu servidor:
| Campo | Valor | Notas |
| :--- | :--- | :--- |
| **Tipo** | `SRV` | |
| **Servicio** | `_minecraft` | |
| **Protocolo** | `_tcp` (o `TCP`) | |
| **Nombre / Host** | `play` | Usa `@` si quieres que los jugadores se conecten usando solo `tudominio.com` sin `play.` |
| **Prioridad** | `0` | |
| **Peso (Weight)** | `0` | |
| **Puerto** | `[Puerto de tu servidor]` | El puerto numérico asignado en tu panel de control |
| **Destino (Target)**| `play.tudominio.com` | Debe coincidir con el nombre de host CNAME creado en el Paso 2 |
| **TTL** | `Auto` (o `3600`) | |
> **Nota para proveedores con un solo campo "Nombre":** Si tu registrador no tiene campos separados para Servicio/Protocolo, ingresa `_minecraft._tcp.play` en el campo Nombre/Host.

### Paso 4: ¡Listo! ✅
¡Tu dominio personalizado ya está vinculado! Ten en cuenta que los cambios en el DNS pueden tardar unos minutos en propagarse. Una vez actualizado, ¡podrás conectarte a tu servidor usando tu nuevo dominio!
