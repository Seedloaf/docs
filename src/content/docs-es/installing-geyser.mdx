### Paso 1: Elegir el servidor correcto

Geyser [es compatible con Forge](https://geysermc.org/wiki/geyser/setup?platform=modded-servers&host=provider), pero por lo general se recomienda usar Paper/Spigot al ejecutar un servidor con Geyser. El resto de esta guía se mostrará utilizando un servidor Paper en Seedloaf.

### Paso 2: Descargar los plugins

Generalmente, hay 3 plugins que deberías instalar:

1. El plugin de Geyser en sí: es lo que realmente permite la conexión de los jugadores de Bedrock.
2. Floodgate: permite que los usuarios de Bedrock se conecten sin necesidad de tener una cuenta de Java Edition.
3. ViaVersion: permite que clientes con versiones más recientes se conecten a tu servidor.

Para descargar Geyser y Floodgate, [visita esta página](https://geysermc.org/download) y descarga las versiones correspondientes.<br />
Para descargar ViaVersion, [visita esta página](https://viaversion.com/) y selecciona "ViaVersion".

Una vez descargados los plugins, súbelos a la carpeta "plugins" en tu panel de control y ¡inicia el servidor para que se carguen!

### Paso 3: Configurar el plugin y el servidor

1. Ve a Configuración (Settings), desplázate hasta Puertos Adicionales (Additional Ports) y expón el puerto 19132. Copia la dirección generada (ej. 12345:example.seedloaf.gg).
2. Una vez que el servidor se inicie, abre la carpeta geyser -> abre config.yml -> y pega la dirección copiada dentro de los corchetes de advertise-addresses: [].
3. A continuación, busca tu archivo <code>server.properties</code> y cambia "enforce-secure-profile" a <code>false</code>; esto permite que los jugadores de Bedrock puedan usar el chat.

Guarda los cambios y vuelve a iniciar tu servidor para que las modificaciones surtan efecto.

### Paso 4: Conectarse desde Bedrock
Una vez que tu servidor haya iniciado por completo, los jugadores de Bedrock podrán unirse usando el puerto `19132` y la dirección `TU_IP.seedloaf.gg`.

### Paso 5: ¡A divertirse!

Tu servidor ya debería estar listo para recibir a jugadores de Bedrock. ¡Que lo disfrutes!
