---
title: Instalar paquetes de recursos (Resource Packs)
description: Muestra cómo instalar paquetes de recursos para los miembros de tu servidor.
---
¡A continuación encontrarás una guía sobre cómo instalar paquetes de recursos! Antes de comenzar, hay dos cosas que debes tener en cuenta. Primero, todos los paquetes del lado del servidor sobrescribirán a los paquetes del lado del cliente. Segundo, esta guía está dividida en dos partes (Bedrock y Java). ¡Asegúrate de seguir la guía correspondiente a tu caso!

## Para usuarios de Java
**Paso 1: Encuentra un paquete**
Busca un paquete de texturas para Java [.zip]. Asegúrate de no estar usando un paquete de texturas de Bedrock [.mcpack].

**Paso 2: Aloja tu paquete de recursos**
Ve a cualquier sitio web de alojamiento de recursos como https://mc-packs.net/ y carga el paquete. Una vez cargado, copia la URL proporcionada y regresa a tu panel de control.

**Paso 3: Añádelo a tu servidor**
Abre tu archivo server.properties y desplázate hasta encontrar <code>resource-pack=</code>, luego pega el enlace que copiaste y ¡haz clic en guardar!

## Para usuarios de Bedrock
**Paso 1: Encuentra un paquete**
Busca un paquete de texturas para Bedrock [.mcpack]. Asegúrate de no estar descargando un paquete de texturas de Java [.zip].

**Paso 2: Añádelo a tu servidor**
Ubica la carpeta de paquetes de Bedrock (archivos -> plugins -> geyser -> packs) y ¡carga allí el paquete que descargaste!
