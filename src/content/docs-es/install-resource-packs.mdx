---
title: Instalación de paquetes de recursos
description: Muestra cómo instalar paquetes de recursos para los miembros de tu servidor.
---
¡A continuación encontrarás una guía sobre cómo instalar paquetes de recursos! Antes de comenzar, ten en cuenta dos cosas. Primero, todos los paquetes del lado del servidor sobrescribirán los paquetes del lado del cliente. Segundo, esta guía está dividida en dos partes (Bedrock y Java). ¡Asegúrate de seguir la guía relevante para ti!

## Para miembros de Java
**Paso 1: Encuentra un paquete**
Encuentra un paquete de texturas para Java [.zip]. Asegúrate de no estar usando un paquete de texturas para Bedrock [.mcpack].

**Paso 2: Aloja tu paquete de recursos**
Ve a cualquier sitio web de alojamiento de recursos como https://mc-packs.net/ y sube el paquete. Una vez subido, copia la URL proporcionada y regresa a tu panel de control.

**Paso 3: Añádelo a tu servidor**
Abre la pestaña <code>server.properties</code> y desplázate hasta encontrar <code>resource-pack=</code>, luego pega el enlace que copiaste y ¡haz clic en guardar!

## Para miembros de Bedrock
**Paso 1: Encuentra un paquete**
Encuentra un paquete de texturas para Bedrock [.mcpack]. Asegúrate de no estar descargando un paquete de texturas para Java [.zip].

**Paso 2: Añádelo a tu servidor**
Ubica tu carpeta de paquetes de Bedrock (plugins -> geyser -> packs) y ¡sube allí el paquete que descargaste!

### ✅ ¡Disfruta de tu nuevo paquete de texturas!
