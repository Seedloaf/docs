---
title: Setting Up Cracked
description: Shows you how to allow unofficial clients to join your game.
---
### Enabling Cracked
1. Go to your settings tab and find the server properties section<br></br>
2. Disable <code>Online Mode</code><br></br>
3. Save and restart your server<br></br>

### Joining a Cracked Server
Cracked users can now join through your seedloaf.gg domain! If you have IP issues joining, you can try joining by using <code>port:ip</code>.<br/><br/> 
Example: <code>12345:example.seedloaf.gg</code>
