### Step 1: Choosing the correct server

Geyser [does support Forge](https://geysermc.org/wiki/geyser/setup?platform=modded-servers&host=provider),
but it is generally recommended you use Paper/Spigot when running a Geyser server. The remainder of this
guide will be shown using a Paper server on Seedloaf.

### Step 2: Download the plugins

There are generally 3 plugins you should install:

1. The Geyser plugin itself - this is what actually allows Bedrock players to connect.
1. Floodgate - this allows Bedrock users to connect without requiring a Java Edition account.
1. ViaVersion - this allows clients with newer versions to connect to your server.

To download Geyser and Floodgate, [visit this page](https://geysermc.org/download)
and download the correct versions.<br />
To download ViaVersion, [visit this page](https://viaversion.com/) and select "ViaVersion"

Once you have downloaded the plugins, upload them to the "plugins" file on your dashboard than start the server so the plugins can be loaded!

### Step 3: Configuring the plugin and server

1. Find geyser's <code>config.yml</code> and change "auth-type" to <code>"floodgate"</code>
2. While you're in the config file, change "clone-remote-port" to <code>true</code>
3. Next, find your <code>server.properties</code> file and change "enforce-secure-profile" to <code>false</code> - this allows bedrock players to use the chat

Save your changes and start your server again for the edits to come into effect.

### Step 4: Connecting through bedrock
Go to your `console` tab and there you should see your server IP and Port ready to go! Before connecting, make sure to disable any addblockers or VPNs as that tends to cause bugs when joining!

### Step 5: Have fun

Your server should now be ready to accept Bedrock players - enjoy!
