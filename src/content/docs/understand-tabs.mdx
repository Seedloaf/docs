You might be confused on how to setup / configure your server. Do not panic, as this will guide you through where to find everything you will need!

### Dashboard
This is where you can see your server's performance, which includes CPU speeds, RAM usage, and storage consumption. Below that will give you access to your server's console. You can type Minecraft commands inside as if you were OP'ed on a server.

### Settings
    1. Server Preview: This is where you can change your server MTOD as well as your server icon!

    1. Server Properties: This gives you the control on how your server operates, which includes the game's difficulty, default gamemode, maximum amount of players, server description, and many others. This also allows you to dowload experimental builds of your loader and disable the online authentication, aka cracked mode.

    1. Server Configuration: Here is where you can change your java version, JVM arguments, and your server timezone.

    1. Additional Ports: As the name implies, this is where you can open additional ports for your server! This is very useful for some plugins such as simple voice chat.

    1. Danger Zone: Careful! This is where you can delete your server. Keep in mind that doing so will permanetly delete the server from our systems including all your settings, files, and backups! Only do this if you are sure you want to delete it.

### Files
    1. File Manager: This is where you can add, remove, and configure your server's files. If you've never started your server before, it may look completly blank. This can be fixed by simply starting your server and refreshing the page.

    1. Upload World: This is where you can upload worlds to seedloaf! For more information on importing a world, check out this [guide](https://seedloaf.com/documentation/custom-world-upload).

    1. Backups: Here, you can create and download backups! These backups contain everything from your server including inventories, file configs, and more! We recommend downloading a backup every once in a while to make sure it's safe in case an accident happens.

### Access
    1. In-game access: This is where you configure who can join (everyone by default) and who has permission to use commands on your server!

    1. Dashboard access: This section allows you to give other people access to your dashboard! Just put in their account's email and set what permission level you wish to grant them. For more detailed information, check out this [guide](https://seedloaf/documentation/add-users)
---

Now you understand how each tab works, and can confidentally explore Seedloaf with no hassle!
