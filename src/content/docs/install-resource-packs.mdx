---
title: Installing Resource Packs
description: Shows you how to install resource packs for members of your server.
---
Below is a guide  on installing resource packs! Before you begin, keep in mind that any server side resource packs will override client side packs!
### Step 1: Find a Pack
Find a Java texture pack [.zip]. Ensure you are not using a Bedrock texture pack [.mcpack].

### Step 2: Host Your Resource Pack
Go to any resource hosting website such as https://mc-packs.net/ and upload the pack. Once it's uploaded, copy the given URL and go back to your dashboard.

### Step 3: Add It To Your Server
Open your server.properties tab and scroll until you find <code>resource-pack=</code> than paste the link you copied and click save.

### Step 4: Done ✅
Resource pack should now be added! Restart your server and enjoy!
